## Автоматизация жестов и поиск элементов в Appium

###  Цель:
Научиться:
- работать с сенсорными событиями (*Touch Action / W3C Actions*);
- реализовывать циклы со свайпами для поиска динамических элементов;
- формировать отчеты о прохождении тестов.

###  Описание:

####  Часть 1: Настройка и первый свайп

1. Подготовьте среду:
   - Python  
   - Appium Server  
   - Эмулятор или реальное устройство  
   - Установленное приложение **PNW**

2. Напишите базовый конфиг (*Desired Capabilities*) для подключения к приложению.


#### Часть 2: Реализация логики поиска "Календаря"

1. Напишите скрипт, который:
   - открывает главный список приложений или настроек в **PNW**

2. Создайте цикл `while`, который:
   - выполняет свайп вниз  
   - продолжает выполнение, пока элемент с текстом **"Календарь"** (или соответствующим ID) не станет видимым  

3. Добавьте проверку:
   -  Если элемент найден → кликнуть по нему  
   -  Если достигнут конец списка и элемент не найден → выбросить исключение с понятной ошибкой  

4. Сгенерируйте отчет о выполнении:
   - через стандартные логи Appium  
   - или с использованием **Allure**

### Критерии оценки:

Статус **"Принято"** ставится, если:

-  Тест успешно запускается и находит приложение **"Календарь"** через свайпы  
-  Код написан на Python с использованием библиотеки `Appium-Python-Client`  
-  Реализована обработка исключений
